# The Future of Software Engineering

## An article worth reading

[The Future of Software Engineering Isn't What You Think](https://medium.com/@ahmad.al.dahle/the-future-of-software-engineering-isnt-what-you-think-96abb293d70a) explores how AI coding tools may change software engineering. Rather than treating faster code generation as a reason engineers will disappear, the article compares AI tools to power tools for carpenters: useful technology that changes the work without eliminating the craft.

I find this perspective interesting because it shifts the focus from typing code to the broader skills that make software valuable. Understanding a problem, making thoughtful design decisions, communicating with people, and maintaining reliable systems are still essential. AI can make implementation faster, but engineers remain responsible for deciding what to build and evaluating whether it solves the right problem.
